# music-journal
Mood-Based Music Journal

Users log their mood each day and connect a song to it. Over time, the app has a personal
emotional playlist history.

1. Users track emotions in a creative way
2. Connect moods with music choices
3. Have a timeline of emotional patterns

1. Front-end with HTML/CSS/JS for mood selection (icons/sliders?) and song input.
2. Back-end (Node.js, Python?) for handling user interaction.
3. Database to store user profiles, moods, and song links.
4. User authentication (password?) for private journals.
5. Responsive design for mobile use (daily quick records?).

Users get a visual and emotional history of their moods. The app provides unique data, with
feelings and music preferences put together.
